# 游戏 Q11 灯效



## 模式名称（循环顺序）



| 称谓 | 说明 |

|------|------|

| **关闭** | 灯灭 |

| **纯色** | 全键盘单色常亮 |



## 操作



与办公键盘相同（仅模式数量不同）：



| 操作 | 功能 |

|------|------|

| 按住左旋钮 + **左空格** | 上一模式 |

| 按住左旋钮 + **右空格** | 下一模式 |

| 旋转左旋钮 | 亮度 |

| 旋转右旋钮 | 音量 |

| 按住左旋钮 + ← / → | 色相 |

| 按住左旋钮 + ↑ / ↓ | 饱和度 |
