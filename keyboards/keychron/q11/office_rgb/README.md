# 办公 Q11 灯效

keymap：`default` · 源码：`office_rgb.c` + `rgb_matrix_user.inc`

## 模式循环

**关闭 → 纯色 → 纯色涟漪 → 纯色波浪 → 办公彩**

| 称谓 | 说明 |
|------|------|
| **关闭** | 灯灭 |
| **纯色** | 左右半区双色常亮 |
| **纯色涟漪** | 打字光晕：中心 400ms 渐灭；邻键延迟 40ms、50% 亮度、250ms 渐灭；曼哈顿一圈 |
| **纯色波浪** | 单色亮度带左→右；波至约 2/3 处下一波出现 |
| **办公彩** | 分区固定配色，不可调 |

## 操作

| 操作 | 功能 |
|------|------|
| 按住左旋钮 + **左空格** | 上一模式 |
| 按住左旋钮 + **右空格** | 下一模式 |
| 旋转左旋钮 | 亮度 |
| 旋转右旋钮 | 音量 |
| 按住左旋钮 + 方向键 | 见下表 |

### 按住左旋钮 + 方向键

| 模式 | ← / → | ↑ / ↓ |
|------|-------|-------|
| 纯色 | 左半色相 | 右半色相 |
| 纯色涟漪 / 纯色波浪 | 全局色相 | — |
| 办公彩 | 无效 | — |

## 办公彩分区配色

| 分区 | 键位 | 色相 | 饱和度 | 亮度 |
|------|------|------|--------|------|
| 主键区 | 字母、数字等 | 160（青绿） | 120 | 100% |
| 导航区 | Home、PgUp/Dn、方向键 | 160 | 90 | 90% |
| 功能行 | 顶行 F 区 | 200（紫） | 200 | 100% |
| 修饰键 | Ctrl、Shift 等 | 210 | 80 | ≈35% |

RCtrl 走修饰键配色，不纳入导航区。
