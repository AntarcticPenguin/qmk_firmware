# Q11 共用灯效

源码目录：`q11_rgb/` · 办公 / 游戏 keymap 编译同一份代码，仅 **循环模式列表** 不同。

## 模式 ID

| ID | 称谓 | 说明 |
|----|------|------|
| `Q11_RGB_OFF` | 关闭 | 灯灭 |
| `Q11_RGB_SOLID` | 纯色 | 左右半区可独立色相/饱和度 |
| `Q11_RGB_RIPPLE` | 纯色涟漪 | 打字光晕 |
| `Q11_RGB_WAVE` | 纯色波浪 | 单色亮度带左→右 |
| `Q11_RGB_ZONE` | 分区彩 | 分区固定配色，不可调 |

## 各 keymap 循环列表

在 keymap `config.h` 定义 profile：

| keymap | 定义 | 循环顺序 |
|--------|------|----------|
| `default`（办公） | `Q11_RGB_PROFILE_OFFICE` | 关闭 → 纯色 → 涟漪 → 波浪 → 分区彩 |
| `gaming`（游戏） | `Q11_RGB_PROFILE_GAMING` | 关闭 → 纯色 |

改 `q11_rgb.c` / `rgb_matrix_kb.inc` 一处，两块键盘重新编译即同步。

## 通用操作

| 操作 | 功能 |
|------|------|
| 按住左旋钮 + 左/右空格 | 上一 / 下一模式 |
| 旋转左旋钮 | 亮度 |

## 纯色模式（`Q11_RGB_SOLID`）

前提：**始终按住左旋钮**（`ENC_L`），再按下列键。仅在此模式下生效；涟漪/波浪见下节。

| 按键 | 作用 | 说明 |
|------|------|------|
| ← / → | 左半色相 | 16 档色环；**← 与 ↑ 同向**，**→ 与 ↓ 同向**；仅左半区（涟漪/波浪下 ←/→ 为全局） |
| ↑ / ↓ | 右半色相 | 同上 16 档，仅右半 |
| PgUp / PgDn | 左半饱和度 | 8 档（见下）；PgUp 更浓，PgDn 更浅 |
| Ins / Del | 右半饱和度 | 同上 |

### 色相色环（16 档）

←/→ / ↑/↓ 在固定色环上逐步切换，不再按 hue±8 连续微调。8 个**标准色**（与 QMK `HSV_*` 一致）+ 相邻标准色之间的**过渡档**（中点 hue）：

| 顺序 | hue | 称谓 |
|------|-----|------|
| 1 | 0 | 红 |
| 2 | 10 | 红→橙 |
| 3 | 21 | 橙 |
| 4 | 32 | 橙→黄 |
| 5 | 43 | 黄 |
| 6 | 64 | 黄→绿 |
| 7 | 85 | 绿 |
| 8 | 106 | 绿→青 |
| 9 | 128 | 青 |
| 10 | 149 | 青→蓝 |
| 11 | 170 | 蓝 |
| 12 | 180 | 蓝→紫 |
| 13 | 191 | 紫 |
| 14 | 202 | 紫→品红 |
| 15 | 213 | 品红 |
| 16 | 234 | 品红→红 |

以前每档只差 8 个 hue（约 32 步绕一圈），相邻档在部分区间肉眼难分——既有 HSV 色环不均匀（黄绿区 hue 变化不显色）的因素，也有步进过密的原因。改为标准色锚点 + 过渡档后，每按一次都有明确色名预期。

### 饱和度（8 档）

默认 `{205, 215, 225, 233, 240, 246, 251, 255}`（红/蓝/紫等）。**黄区**（hue 18–72）、**青区**（100–155）用抬高低端的专用表，避免降到底像暖白/冷白：

| 区 | 8 档 S 值 |
|----|-----------|
| 默认 | 205 → … → 255 |
| 黄 | 228 → 234 → 238 → 242 → 246 → 250 → 253 → 255 |
| 青 | 222 → 228 → 233 → 238 → 243 → 248 → 252 → 255 |

**为何黄降饱和易趋近白**：满饱和黄 ≈ `(255,255,0)`，降 S 时 R/G 已在顶，只会抬高 B → `(255,255,~50)`，高明度下肉眼偏白；红/蓝降 S 仍明显带色。左右半区共用档位逻辑，按各自当前色相选表。

### 与涟漪 / 波浪的差异

| 按键 | 纯色 | 涟漪 / 波浪 |
|------|------|-------------|
| ← / → | 左半色相 | 全局色相（16 档，**←/→ 方向与纯色一致**） |
| ↑ / ↓ | 右半色相 | 无作用 |
| PgUp / PgDn | 左半饱和度（8 档） | 连续饱和度 |
| Ins / Del | 右半饱和度（8 档） | 无作用 |

各模式调色在**运行时**互不覆盖；重启后恢复固件默认值。

### 实现备忘（维护用）

QMK 灯效 ID：`RGB_MATRIX_CUSTOM_q11_static_solid`（`rgb_matrix_kb.inc`）。

Split 键盘通过 `rgb_matrix_config` 同步左右半区参数（仅纯色渲染时按此解释）；渲染按 **LED 序号**（前 42 颗左半）取色，不用 `is_keyboard_left()`：

| 字段 | 含义 |
|------|------|
| `hsv.h` | 左半色相 |
| `hsv.s` | 右半色相（**不是** HSV 饱和度） |
| `speed` 高 4 位 | 左半饱和度档位 |
| `speed` 低 4 位 | 右半饱和度档位 |
