# Q11 共用灯效

源码目录：`q11_rgb/` · 办公 / 游戏 keymap 编译同一份代码，仅 **循环模式列表** 不同。

## 模式 ID

| ID | 称谓 | 说明 |
|----|------|------|
| `Q11_RGB_OFF` | 关闭 | 灯灭 |
| `Q11_RGB_SOLID` | 纯色 | 左右半区双色常亮 |
| `Q11_RGB_RIPPLE` | 纯色涟漪 | 打字光晕 |
| `Q11_RGB_WAVE` | 纯色波浪 | 单色亮度带左→右 |
| `Q11_RGB_ZONE` | 分区彩 | 分区固定配色，不可调 |

## 各 keymap 循环列表

在 keymap `config.h` 定义 profile：

| keymap | 定义 | 循环顺序 |
|--------|------|----------|
| `default`（办公） | `Q11_RGB_PROFILE_OFFICE` | 关闭 → 纯色 → 涟漪 → 波浪 → 分区彩 |
| `gaming`（游戏） | `Q11_RGB_PROFILE_GAMING` | 关闭 → 纯色 |

改 `q11_rgb.c` / `rgb_matrix_kb.inc` 一处，两块键盘重新编译即同步。

## 操作

| 操作 | 功能 |
|------|------|
| 按住左旋钮 + 左/右空格 | 上一 / 下一模式 |
| 旋转左旋钮 | 亮度 |
| 按住左旋钮 + ←/→ | 纯色：左半色相；涟漪/波浪：全局色相 |
| 按住左旋钮 + ↑/↓ | 纯色：右半色相 |
| 按住左旋钮 + PgUp/PgDn | 饱和度（纯色 5 档 0→满；涟漪/波浪连续） |

各可调模式颜色独立保存（纯色 / 涟漪 / 波浪互不影响）。

## 文件

| 文件 | 作用 |
|------|------|
| `q11_rgb.c` | 模式切换、调色、分区配色 |
| `q11_rgb.h` | 对外 API |
| `q11_rgb_profile.h` | 各 keymap 循环列表 |
| `rgb_matrix_kb.inc` | QMK 自定义灯效实现 |
| `rgb_config.h` | 共用 RGB 基线（禁用内置动画等） |
