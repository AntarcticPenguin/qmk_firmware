## 定制目标

我是**左手键盘**用户，希望把日常最常用的编辑快捷键放到**键盘右手区域**，方便单手操作。

右手固定手位，**只动大拇指和食指**单手操作。详细映射表、备用槽位、IDEA 快捷键备忘见 **`快捷键规划.md`**。

## 如何添加新快捷键

1. 打开 `keymaps/default/keymap.c`
2. 在 `process_record_user()` 的 `switch (keycode)` 里增加新的 `case`
3. 用 `IS_MAC_LAYER()` 区分 Mac（Cmd）与 Windows（Ctrl）
4. 重新编译固件并刷入

示例（右 Ctrl + 某键 → 全选）：

```c
case KC_HOME:
    shortcut = IS_MAC_LAYER() ? LGUI(KC_A) : LCTL(KC_A);
    break;
```

## 编译固件（生成 .bin）

源码在 `keyboards/keychron/q11/ansi_encoder/`，编译产物放到 `firmware/office/`（办公用）；游戏用固件在 `firmware/gaming/`：

```
qmk_firmware/
  firmware/
    gaming/
      keychron_q11/        ← 游戏用 Q11（此前生成的固件在此）
        latest.bin
        archive/
    office/
      keychron_q11/        ← 本键盘（办公 Q11）
        latest.bin         ← 刷机用这个
        archive/
```

**推荐：运行本目录编译脚本**

```powershell
cd C:\Tools\qmk\qmk_firmware\keyboards\keychron\q11\ansi_encoder
.\compile.ps1
```

脚本会编译、复制到 `firmware/office/keychron_q11/`，并清理 QMK 根目录临时 `.bin`。

## 刷写固件

Q11 为分体键盘，**左右两半需分别刷写**：

1. 进入刷写模式：按住 **Esc**（主控侧）或 **Del**（从控侧），再插入 USB
2. 使用 [QMK Toolbox](https://github.com/qmk/qmk_toolbox) 刷入 `firmware/office/keychron_q11/latest.bin`
3. 先刷主控侧，再刷从控侧

## USB 版本号（Keychron Launcher）

| 项目 | 值 |
|------|-----|
| QMK 上游 `keyboard.json` | `1.0.0`（拉最新代码也不会变，Keychron 未合入） |
| 原厂 `stock_..._v1.1.bin` | Launcher 显示 **1.0.1** |
| 本 keymap 覆盖 | `keymaps/default/config.h` → `DEVICE_VER 0x0101` |

改版本号后需重新 `.\compile.ps1` 并刷机，Launcher 里才会显示 1.0.1。

**注意**：自定义 QMK（改了 `keymap.c`）即使用 1.0.1，Keychron 网页端/Launcher **仍可能无法完整识别**（它面向原厂固件协议，不是通用 VIA）。灯光、在线改键等原厂功能不要依赖网页；快捷键需求在本仓库直接改固件即可。

原厂固件备份：`firmware/gaming/keychron_q11/archive/stock_keychron_q11_us_knob_v1.1.bin`
