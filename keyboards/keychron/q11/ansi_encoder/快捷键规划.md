# Q11 右手快捷键规划

> 状态：**已实现**（已写入 `keymap.c`，空槽待后续填充）  
> 设计原则：右手固定手位，**只动大拇指和食指**即可单手操作

## 右手物理键区（参考）

```
右侧竖列：Ins | Del | PgUp | PgDn | Home
底行：          右Alt | Fn | 右Ctrl | ← | ↓ | →
上一行：                              ↑
```

---

## 一、主映射（已实现）

### 单击（按下放开）

| 键盘操作 | 快捷键 | 功能 | 固件 |
|----------|--------|------|------|
| Home | `Ctrl+C` | 复制 | ✅ |
| PgDn | `Ctrl+V` | 粘贴 | ✅ |
| PgUp | `Ctrl+A` | 全选 | ✅ |

定制快捷键**固定发 Windows `Ctrl`**（与背面 Mac/Win 拨码无关，IDEA 用）。

### 组合键（已实现）

| 键盘操作 | 快捷键 | 功能 | 固件 |
|----------|--------|------|------|
| Home 按着 + ← | `Ctrl+Z` | 撤销 | ✅ |
| Home 按着 + ↓ | `Ctrl+Shift+Z` | 重做 | ✅ |
| 右 Ctrl 按着 + Home（按下时） | `Ctrl+X` | 剪切 | ✅ |
| 右 Ctrl 按着 + PgDn（按下时） | `Win+V` | Windows 剪贴板历史 | ✅ |
| 右 Ctrl 按着 + `\` | `Ctrl+E` | IDEA 最近文件 | ✅ |
| 右 Ctrl 按着 + Backspace | `Ctrl+Shift+Backspace` | 跳到最后编辑处 | ✅ |

## 五、实现说明

- 逻辑在 `keymap.c` → `process_record_user()`
- 短按：200ms 内松开 → 复制/粘贴/全选（需先松开右 Ctrl，避免误触发剪切/剪贴板）
- 右 Ctrl + Home/PgDn：按下瞬间触发剪切 / Win+V
- Home 按住 + ←/↓：模拟按住 Ctrl 连按 Z，支持长按连续撤销/重做
- 右 Ctrl + `\` / Backspace：每次按下均可触发，可连续使用
- 固定 `LCTL`，不随 Mac 层发 `Win` 键
- 仅在 `MAC_BASE` / `WIN_BASE` 层生效
